# Project documents

Everything written about the project (not the app code) is in this folder.

| Folder | What is inside |
|---|---|
| `report/` | The capstone project report (Word and PDF) and the front pages |
| `presentation/` | The final college presentation (`.pptx` and `.pdf`), built from the college template |
| `guides/` | Short guides for the viva: `DevForge_AI_Structure_Guide.pdf` (what each file does), `DevForge_AI_How_It_Works.pdf` (the system in simple words), `DevForge_AI_Models_Guide.pdf` (which models and which hardware), and `Project_Understanding_Guide/` |
| `prd/` | Product Requirements Document (what was planned), its figures and the scripts that build it |
| `pitch/` | Earlier startup pitch decks and the script that generated them |

Where the rest of the project lives (one level up):

| Folder | What is inside |
|---|---|
| `devforge/` | **The application** (current version 3.0) |
| `tests/` | Automated tests for the application |
| `legacy_v2/` | The older prototype (version 2.x) that the report describes. Run it from inside this folder |
| `samples/` | Example projects generated by DevForge AI, and output from the old prototype |
| `other_coursework/` | Other subjects (ICS practicals, research methodology manual). Not part of this project |
